# 🏫 Dashboard Escolar - EduFuturo

Este projeto é um painel de controle administrativo completo para ambiente escolar, desenvolvido com tecnologias front-end padrão (HTML5 e CSS3).

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico** (`<header>`, `<aside>`, `<main>`, `<section>`, `<footer>`)
- **CSS3 Moderno**:
  - **CSS Grid** para o painel de métricas e estrutura da aplicação.
  - **Flexbox** para componentes como menu, cabeçalho e alinhamento do conteúdo.
  - **Design Responsivo** com breakpoints para tablets e dispositivos móveis.
  - **Variáveis CSS** (Custom Properties) para facilidade de personalização do tema.

## 📁 Estrutura do Projeto

- `index.html` — Estrutura lógica da aplicação.
- `style.css` — Estilização, layout e responsividade.
- `imagens/` — Diretório reservado para imagens como logos e banners.

## 📌 Como Executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` diretamente em seu navegador.
